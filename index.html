常见问题

真的完全免费吗？

是的。没有广告、没有会员、没有内购，所有功能都可以直接使用。AI 功能需要填入你自己在 AI 服务商申请的 API Key，相关费用（不少服务商有免费额度）由你和服务商结算，我们不收取任何费用。

我的数据存在哪里？

只保存在你的手机上，不经过我们的服务器。你可以备份到自己的 iCloud、WebDAV（如坚果云）、Google Drive、OneDrive 或百度网盘，备份文件也只在你自己的网盘里。

换手机或者多台设备怎么用？

在「我的 → 数据备份与恢复」备份到网盘，新设备连接同一个网盘恢复即可。打开「多端实时同步」后，多台设备之间大约 1 分钟自动同步一次。

不填 AI Key 能记账吗？

能。一句话记账、Siri 记账都可以直接用。在「我的 → AI 引擎」填入 API Key（支持 DeepSeek、Kimi、通义千问、智谱、Gemini 等）后，复杂长句的识别和拆分更准确，还能生成 AI 总结信和年度报告。

可以和家人一起记账吗？

可以。「家庭共享账本」最多 3 人，大家用同一个专用坚果云账号同步，各自记的支出和收入都会出现在共享账本里。

安卓下载后是 .zip 文件怎么办？

部分浏览器会把安装包保存成 .zip，把文件名末尾的 .zip 删掉（变成 .apk）再点开即可安装。

支持哪些设备？

iPhone、iPad 和安卓手机。界面支持简体中文、繁體中文、English 和日本語。
