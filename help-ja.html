クイック記録と AI の魔法

  • Siri とひと言記帳：手を使わずに記録！Siri に「Daily Trifles で記帳」と話しかけるだけ。ホーム画面の入力欄（または音声）は内容を自動で読み取ります：
    • 基本：「タクシー 25」と入力するだけで保存。
    • 口座を指定：「タクシー 25 Alipay」と入力すると自動で分類。
    • 日付を指定：「昨日 タクシー 25」と入力すると昨日の記録が作成され、その日まで自動でスクロール。「2026年8月1日 タクシー 25」のような日付も使えます。
    • 振替：「WeChat から Alipay に振替 100」と入力すると振替が作成されます。
動画を見る： 再生する
  • AI による解析：「マイページ → AI エンジン」で API キーを入力すると有効になります。「スーパーでスペアリブを50円分買って、子どものスマホに100円チャージした」のようなくだけた長文でも、AI が執事のように複数の記録にきっちり分けてくれます！
  • 自分専用のキーワード：「マイページ → カテゴリ管理」でサブカテゴリにキーワードを追加すると（例：「外食」に「マクドナルド」）、そのキーワードを含む文を入力したときに正確に分類されます。

しっかり手入力の家計簿

  • 複数の帳簿：「家庭」「個人」「会社」など複数の独立した帳簿を作成でき、「マイページ」→「帳簿管理」で追加・管理します。帳簿の切り替えは、ホーム上部の統計パネルの左上、手動記録ページの右上、「マイページ」→「帳簿管理」の 3 か所からできます。帳簿ごとに記録と統計は完全に分かれているので、仕事とプライベートなど複数のお金の管理もすっきり整理できます。
  • 共有帳簿：「帳簿管理」→「👥 共有帳簿」で家族（最大 3 人）と同じ帳簿に記録できます。詳しくは「家族の共有帳簿」👆。
  • スクショ記帳とクイック記録：iOS 専用の便利な機能を用意しています！「マイページ → クイック記録ガイド」で、Siri の音声コマンドと背面タップでのスクショ記帳を設定できます。WeChat Pay や Alipay の明細から金額とカテゴリを自動で読み取ります。
  • 手入力と電卓：画面下の をタップして手入力を開きます。まず「日時」ボタンの左側で支払い元の口座を確認・変更してください。金額キーボードには + - × ÷があるので、複数の品物もそのまま計算できます。 = をタップすると合計が出ます。
  • よく使う記帳のショートカット：「メモを入力...」をタップすると、過去3か月の記録をもとに、よく使うテンプレートが下に並びます。テンプレートをタップすると、メモだけでなく当時の金額・カテゴリ・支払い口座まで自動で入力されます！毎月の決まった支出を何度も入力する手間が省けます。
  • 振替と収支対象外：左上で「振替」に切り替えると、収支の集計に影響しない記録を作成できます。特別な資金は「収支対象外」の口座に記録できます。
  • 返金：ネット通販の返品や返金は、記録の詳細で「返金」を選ぶだけ。対応するカテゴリの支出から自動で差し引かれ、統計に実際の純支出が反映されます。
  • 貸し借り：貸したお金、借りたお金、敷金や手付金の受け払いは収支に含めず、専用の貸借口座で管理します。詳しくは「貸し借り」の章をご覧ください。

日記と思い出

  • Siri で音声メモ：「Siri、Daily Trifles に記録」と話しかけるだけで、手を使わずに日記が書けます！
    💡 注意点：Siri は音声入力中に0.8秒以上止まると自動で終了するため、歩いているときや運転中のふとしたひらめきや短い気持ちの記録に向いています。
  • 長文の音声と集中モード：考えながらたっぷり書きたいときは、画面下の をタップ（または40文字以上入力）して全画面の日記を開きます。そこで入力欄の右下にある 「録音」ボタンをタップすると、この日記に音声を録音できます。文章を書き終えたら AI でワンタップ推敲も！話した内容をそのまま文字にしたいときは、キーボードの音声入力を使ってください。
  • 🎙️ 日記の録音：全画面の日記で下の「録音」ボタンをタップすると録音パネルが表示されます。いつでも一時停止・再開でき、「完了」で保存。1回の録音は最長 5分（残り30秒でカウントダウンが表示され、時間になると自動保存）です。日記1件につき1つ、1日最大4つまで。録音後は再生・削除ができ、ホーム・カレンダー・あの日の今日・検索結果からそのまま再生できます（1.5倍速対応）。録音中にアプリを切り替えたり電話がかかってきたりすると自動で一時停止し、戻ると再開できます。録音は写真と同じくクラウドに自動バックアップされ、機種変更時にも復元され、ZIP エクスポートにも含まれます。検索で「録音あり」を選ぶと、録音付きの日記をすぐに探せます。
  • 🗂 日記の下書き：全画面の日記を書きかけで閉じたいときは、左上の終了ボタンで「下書きを保存」を選べば保存されます。保存前にアプリを閉じてしまっても、次回起動時に自動で下書きとして保存されます。下書きがあると、全画面の日記の右上（チェックボタンの下）に「下書き」が表示され、右上の数字が下書きの数です。ホーム画面右下の ボタンにも下書きの数が表示されます。「下書き」をタップすると一覧が開き、1件選んで編集を続けられます。日記として保存すると下書きからは自動で削除されます。下書きはこの端末にのみ保存され、クラウドにはバックアップされません（最大20件）。保存済みの日記を編集するときは下書きは使われません。長押しすると複数選択でき、まとめて削除できます。
  • 📝 録音の文字起こし（iPhone）：全画面の日記で、録音バーにある「文字起こし」ボタンをタップすると録音を文字に変換でき、保存前に修正できます。変換したテキストは録音バーの下に「文字起こし」ラベル付きで表示され、本文とは分けて保存されます。あとから編集・削除しても録音は影響を受けません。認識はすべて端末内で行われ、録音がアップロードされることはありません。文字起こしも検索でき、日記と一緒にバックアップされます。オフライン認識に非対応と表示された場合は、iPhone の「設定 → 一般 → キーボード」で「音声入力」をオンにしてから再度お試しください。
  • 写真と周囲の情報：高画質の写真を最大20枚、タグを10個まで追加でき、気分スタンプも押せます。アプリが天気と位置情報をそっと記録し、そのときの空気や気持ちを思い出として残します。
  • 📍 場所と天気：全画面の日記の上部にある「場所・天気」は、それぞれタップして変更できます。場所をタップすると「場所を設定」パネルが開き、「市＋区／区／番地」の3段階から選ぶか、手入力できます。右上の「現在地を取得」で現在地の住所に切り替えられます。天気をタップすると16種類の天気から選べ、温度バーを左右にドラッグして気温を設定できます。「再取得」で現在地の天気を再取得します。場所・天気の右にある ✕ で、その項目だけを削除できます。
  • あの日の今日：ホーム画面に思い出のバナーが出たり、カレンダーのアイコンが ✨ と光ったりしたら、今日の思い出があります！バナーをタップ（またはカレンダーであの日の今日をタップ）すると、本をめくるように過去の日を振り返れます。過去5年分の今日の日記を書き足すこともできます。あの日の今日ボタン右上の赤い数字は過去の日記の件数、右下の小さなカメラは過去の同じ日の写真があることを示します。写真ライブラリに過去の同じ日に撮った写真があれば、上部に写真のお知らせが表示されます。タップすると年ごとのアルバムが開き、写真を選んでその年のこの日の日記を作成できます。
  • シェイクでランダムに振り返る：カレンダーでランダムに振り返るをタップすると、思い出をどこまでも巡れます。スマホを振ると、軽やかな振動とともに新しい過去の一日がランダムに選ばれます。まるで福袋のような楽しさ！
  • 足あとマップ：カレンダーで 足あとマップをタップすると、地図の上で思い出の足取りをたどれます。数字の付いた円はその場所で書いた日記の数。タップすると「この場所の思い出」ギャラリーが開き、そこでの出来事をじっくり振り返れます。
  • 🖼️ 日記フォト：「マイページ → 日記フォト」では、日記に添付したすべての写真が日付の新しい順に並び、上部で年・月ごとに絞り込めます。写真をタップすると全画面で表示され、左右にスワイプしてめくれます。写真を長押しすると、その日記を見る・写真アプリに保存・共有ができます。
  • 💡 写真をすばやく探すコツ：「あの日の今日」やランダムに振り返る画面、過去の日記の追記で写真を追加すると、その日の日付が自動でクリップボードにコピーされます。写真アプリの検索欄に貼り付ければ、その日の写真が一瞬で見つかります！

ホームダッシュボードと統計

  • 3つのダッシュボード：ホーム画面上部のダッシュボードは左右にスワイプして「日記」「収支」「資産」を切り替えられます。タップすると全画面の統計が開きます。
  • AI まとめと月初のお知らせ：アプリは適応型の Map-Reduce 方式を採用しています。毎月1日になると、ホーム画面の上部に思い出カプセルが表示されます（読むと消えます）。AI がひと月の喜怒哀楽から心温まる「時の手紙」を作成し、年末には12か月を振り返る「年間レポート」を届けます！カプセルを見逃しても、日記統計の［月］／［年］表示からいつでも呼び出せ、端末内のキャッシュならコストゼロですぐに表示されます。
  • 時の記録（日記モード）：ただの数字ではありません。連続記録日数・累計文字数・写真の数をまとめて表示します。「あの日の今日」の思い出がある日は、フローティング通知とカレンダーのきらめきでお知らせします。
  • プライバシーに配慮した収支（家計簿モード）：今月の支出・収入・残高をひと目で表示。目のアイコンをタップすると金額を隠せるので、人前でも安心です。
  • AI 支出分析（家計簿モード）：家計簿の統計画面で「スマート支出分析」バナーをタップすると、AI がさまざまな角度から振り返り、主な傾向、潜在的なリスク、改善の提案、励ましの言葉を含む本格的な家計診断レポートを作成します。右上の「再生成」でいつでも最新の記録をもとに作り直せます。
  • 多角的な分析：週・月・年・全期間・期間指定でレポートを表示でき、1日／1か月あたりの平均も自動で計算。支出の傾向がひと目でわかります。
  • 予算と予算超過のお知らせ：月の総支出やカテゴリごとに予算を設定でき、統計画面に予算の進捗バーがリアルタイムで表示されます。予算に近づいたり超えたりすると、ホーム画面にお知らせが表示され、使いすぎを防げます。
  • 多通貨の自動換算：どの通貨の口座の支出や資産も、設定した基準通貨と最新の為替レートで自動的に換算・集計されます。基準通貨は「マイページ → 資産口座」の右上にある「基準通貨 ▾」で変更でき、変更後は過去の記録もすべて最新レートで換算し直されます。
  • 純資産をリアルタイムで把握：ホームの「資産」ダッシュボード、または「マイページ → 資産口座」で、総資産・総負債・純資産をひと目で確認できます。口座カードは長押しでドラッグして自由に並べ替えられます。

貯金プランと目標

  • 5つの貯金方法： 「自由貯金（いつでも出し入れ）」「定額貯金」「52週貯金」「365日貯金」の4つの定番モードに加え、銀行の定期預金を記録できる「定期預金」も。車の購入資金でも旅行資金でも、ぴったりの方法が見つかります。
  • 実際の振替と連動： チェックインや入金のたびに、「引き落とし口座」から「入金口座」への振替が自動で記録されます。2つの口座の通貨が違う場合も現在のレートで換算されるので、資産は1円単位で正確です。
  • 自動チェックインと進捗管理： 一覧の進捗バーに「貯金済み」と「残り」がリアルタイムで表示されます。1回分を達成すると紙吹雪のアニメーションが流れ、次回の日付も自動で計算されます。
  • 自由な出し入れとアーカイブ： 自由モードではいつでも「入金」「引き出し」ができます（お金は元の口座に戻ります）。目標を達成したプランは自動で達成済みになり、休止中のプランはワンタップで「アーカイブ」して非表示にできます。

🏦 定期預金

  • 作成： 「定期預金」を選び、名称・所属口座（どのカードに預けるか）・預入日・元本・期間（日／月／年）・利率（年利／月利／日利）・利払い方法・満期時の扱いを入力すると、下部に満期日と予想利息がリアルタイムで表示されます。
  • 所属口座： 定期預金はこのカードに属するものとして扱われるため、預け入れや普通預金への振替では振替記録は作成されず、利息収入のみ記録されます。別のカードや両替が必要な場合は、先に「振替」を記録してから作成してください。
  • 利払いと利息： 満期一括、日ごと、月ごと、四半期ごと、年ごとの利払いに対応。利息を受け取ると「投資 - 運用益」の収入として記録されます。日ごとの利息は毎日積み上がり、いつでもまとめて入金できます。
  • 満期時の処理： 満期まで3日以内、または満期を迎えると、「マイページ」の「貯金」に赤い点が表示されます。満期時は普通預金への振替、元本のみ継続、元利継続から選べ、確認するだけで記録が作成されます。満期前の中途解約や、直前の操作の取り消しもできます。

次の章 貸し借り

貸し借り

  • 別に記録する理由： 友人にお金を貸したり、家の敷金を払ったりしても、お金を使ったわけではなく一時的に相手のところにあるだけで、いずれ戻ってきます。そのため貸し借りは専用の「貸借口座」で記録し、収支の統計や予算には含めません。相手が借りている分は総資産に、自分が借りている分は総負債に計上されるので、純資産は常に正確です。
  • 4つの種類： 受け取る側は「貸した」（誰かに貸したお金）と「その他の未収金」（支払った敷金や、立て替えて回収待ちのお金）。支払う側は「借りた」（誰かから借りたお金）と「その他の未払金」（受け取った敷金や前受けの手付金）です。
  • 作成方法： 「マイページ → 貸し借り」または「資産口座 → 貸し借り」を開き、「貸したお金を記録」などのボタンをタップします。相手・金額・日付・返済予定日を入力し、借用書や振込のスクショも添付できます。資金口座を選ぶと、その口座からお金が出入りし残高も連動します。選ばなければ貸し借りだけを登録し、ほかの口座には影響しないので、過去の分を記録するのに便利です。
  • その後の記録： 個別の詳細画面で操作します。「受け取り／返済／回収／返金」は何回かに分けられ、いずれも収支には含まれません。「追加」は追加で貸した・借りた分を記録します。「利息収入／利息支出」は収支に含まれ、元本には影響しません。「貸し倒れ処理」（回収できない場合。支出に計上され、予算には含まれません）と「債務免除」（返さなくてよいと言われた場合。収入に計上）もあります。敷金を家賃に充てたり、手付金を代金に充てたりするときは「支出に振替／収入に振替」。
  • 自動完済： 未回収・未返済の金額がゼロになると自動で完済扱いになり、資産のトップから非表示になります。一覧の「完済済み」から確認でき、追加で記録すると自動で再開されます。
  • 一覧とお知らせ： 一覧は「受け取る／支払う」の2つのタブに分かれ、それぞれ「未完済／完済済み／人別」で表示できるので、誰がいくら借りていて、自分が誰にいくら借りているかがひと目でわかります。貸し借りが期限切れ、または3日以内に期限のときは、「マイページ」の「貸し借り」ボタン右上に赤い点が表示されます。
  • 例： 王さんが2,000円を借りて3回に分けて返す場合：「貸した」を作成し、返済のたびに「受け取り」をタップすれば、完済時に自動で完済扱いになります。家の敷金3,000円を払い、退去時に500円差し引かれた場合：「その他の未収金」を作成し、退去時に2,500円を「回収」、残りの500円は「支出に振替」で家賃や修繕費として記録します。

次の章 きめ細かな予算管理

きめ細かな予算管理

  • 3つの期間で確認： 「週」「月」「年」ごとに予算と残額を確認できます。メインの進捗バーは色でお知らせ：80%で橙色、100%を超えると赤色になります。
  • 大分類・小分類の予算： 総額だけでなく、一覧の大分類や小分類をタップして個別に上限を設定できます（例：「外食 - コーヒー」だけ）。細かな支出までしっかり管理できます。
  • 返金の自動控除と除外： 予算の計算はとても厳密です。「振替」「残高調整」「予算に含めない」記録は自動で除外されます。支出に返金があった場合は純支出で計算し、返ってきたお金はすぐに使える予算に戻ります。
  • ワンタップでデフォルトに： 毎月の予算がほぼ同じなら、月間予算の上部にある「デフォルトに設定」をタップ。今後の各月に自動で適用され、毎回入力する手間が省けます。

次の章 定期記帳と分割払い

定期記帳と分割払い

  • 2種類の自動記録： パネル上部で「定期記帳」と「分割払い」を切り替え、自動化された記録をまとめて管理できます。
  • 定期記帳（自動引き落とし）： 家賃・光熱費・サブスクなどの固定費は、頻度（毎日／毎週／毎月／四半期／毎年）と終了条件（日付または回数）を設定するだけ。時期が来ると自動で記録されます。
  • 分割払い（クレジットカードなど）： 大きな買い物を分割払いにしたら、総額と回数（6回、12回など）を入力するだけで「返済スケジュール」が自動で作成されます。手数料は4つの方式（なし／総額／1回ごと／月利）に対応し、各回の元金と利息がひと目でわかります。
  • 繰り上げ完済といつでも一時停止： 途中で余裕ができたら分割払いを「繰り上げ完済」でき、定期記帳はいつでも「一時停止」できます。その後は新しい記録は作成されませんが、作成済みの記録には一切影響しません。

立替精算の管理

  • 未精算と精算済みのボード： 記帳時に「精算対象」をオンにするだけで、ここに自動で表示されます。「未精算」と「精算済み」に分かれていて、立て替えたお金をしっかり管理できます。
  • 分割・一部精算に対応： 高額な出張費も何回かに分けて精算できます！記録の「純額」から「精算済み金額」を差し引き、残りがいくらかを正確に計算するので、二重計上の心配はありません。
  • 検索ですぐ見つかる： 一覧には強力な検索機能があります。カテゴリ名・メモ・金額、さらには自分で付けたタグ（例： #出張）を入力すれば、照合したい記録がすぐに見つかります。
  • 外貨の自動換算： 月ごとの合計を出すとき、どの通貨で立て替えても、記録時のレートで「基準通貨」に正確に換算し、月間の精算総額をわかりやすく表示します。

便利なメモとリマインダー

次の章 バックアップと復元

バックアップと復元

  • 5つのクラウドから選べる：iCloud、WebDAV（ 坚果云（Jianguoyun）、InfiniCLOUD や Koofr などで無料の WebDAV を申し込むか、自前の Nextcloud や Synology NAS，詳しい設定ガイドを見る👆に接続することもできます）、Baidu Netdisk、Google Drive、OneDrive に対応し、すべて差分の自動バックアップが可能です。どれを何個使うかは自由です。
  • WebDAV のバックアップフォルダ：サーバーアドレスは設定ガイドのとおりに入力すれば OK です（Jianguoyun なら https://dav.jianguoyun.com/dav/）。フォルダを自分で付け足す必要はなく、アプリが末尾に triflesbackup フォルダを自動で追加します。iPhone と iPad ではこのフォルダが自動作成されます。Android では先にクラウドドライブの Web 版で triflesbackup（すべて小文字）というフォルダを作成してください。作成しないと接続時に権限エラーになります。
  • 毎日の自動バックアップ：新しいデータがあると、接続中の各クラウドがそれぞれのタイミングで自動バックアップします（アプリを開いたとき、前面に戻ったとき、バックグラウンドに移ったときなど）。💡 注：バックアップはアプリを前面で使っているときのみ行われます。アバター横のクラウドのロゴが点滅しているのはバックアップ中なので、アプリをスワイプして終了しないでください。
  • 手動エクスポートと復元：「マイページ → バックアップと復元」から、全データを JSON ファイルとして、または画像付きの PDF、ZIP バックアップとしていつでも端末に保存できます。機種変更や再インストール後は、接続済みのクラウドからワンタップで復元するか、端末のバックアップファイルを読み込めます。
  • 他の日記アプリから読み込み：「マイページ → バックアップと復元 → エクスポート／インポート」で「他の日記アプリから読み込む」をタップ：Day One は書き出した ZIP（Day One の設定 →「読み込み／書き出し」→「Day One JSON [ZIP] を書き出す」）を選ぶと、写真・時刻・場所・天気ごと読み込まれます。一本日记 は書き出した .txt ファイルを選ぶと、日付ごとに日記に分割されます（TXT に写真は含まれません）。一叶日记 は「設定 → データ管理 → Markdown を書き出す」で作成した ZIP を選ぶと、本文・時刻・住所・写真がまとめて読み込まれます。同じファイルを何度読み込んでも重複しません。
  • 複数端末のリアルタイム同期 ― バックアップを超えた「持ち歩ける帳簿」：複数の端末（スマホとタブレット、新旧のスマホなど）を使っているなら、これをオンにすると編集内容がほぼリアルタイムで端末間に反映され、通常のバックアップを待つ必要がありません。
  • 新しい端末でメインのクラウドを自動検出：ほかの端末でメインのクラウドを設定済みなら、新しい端末でこれをオンにしたときに自動で検出し、同じ設定にするか確認します。端末ごとに決め直す必要はありません。
  • 💡 家族と一緒に記録したいときは？マルチデバイスのリアルタイム同期は自分の複数の端末用で、日記を含むすべてのデータを同期します。家族と一緒に記録するには「家族の共有帳簿」👆を使ってください。共有されるのは指定した帳簿だけで、日記などの個人データはお互いに見えません。
  • 上級設定 ― 複数クラウドのリアルタイムミラー／今すぐ全クラウドに送信：接続中のすべてのクラウドをできるだけリアルタイムで最新にしたい場合（メインのクラウドだけでなく）は、「複数端末のリアルタイム同期」の詳細設定で「複数クラウドのリアルタイムミラー」をオンにします。また「今すぐ全クラウドに送信」をタップすると、いつでも手動で全体を同期できます。どちらも上級者向けで通信回数が大きく増えるため、普段は使わずオフのままで大丈夫です。

📱 機種変更ガイド

  • 方法1：クラウドにバックアップ → 新しいスマホで復元（おすすめ）：古いスマホで「マイページ → バックアップと復元」から接続済みのクラウドを選び、一度バックアップします。アバター横のクラウドのロゴが点滅しなくなれば完了です。新しいスマホに Daily Trifles をインストールし、同じクラウドのアカウントに接続して「XX から復元」をタップすれば、文章・写真・設定がまとめて戻ります。ファイルを送る必要はなく、iPhone と Android の間でも移行できます。💡 注：iCloud は Apple 端末間でのみ使えます。iPhone から Android に移る場合は WebDAV、Baidu Netdisk、Google Drive、OneDrive を選んでください。
  • 方法2：バックアップを書き出す → 新しいスマホに送る → 読み込む：クラウドを使いたくない場合やネットがない場合に。古いスマホで「マイページ → バックアップと復元 → エクスポート／インポート」を開き、「バックアップ (ZIP)」を選んで「データを書き出す」をタップし、共有メニューから新しいスマホに送ります。新しいスマホで同じ画面を開き、「Daily Trifles のバックアップファイルを選択」でファイルを選んで「データを読み込む」をタップします。
  • 新しいスマホへの送り方：iPhone 同士ならAirDropがいちばん簡単です。Android 同士なら Quick Share、Huawei Share、Xiaomi / OPPO / vivo などの標準の転送機能が使えます。iPhone と Android の間なら、両方に無料の LocalSend をインストールして送るか、クラウドやパソコンを経由してください。WeChat / QQ はファイルサイズに制限があるため、写真の多いバックアップには向きません。
  • 分割されたバックアップ：写真が多いとエクスポートは自動で複数に分割されます。すべてを新しいスマホに送り、読み込み時にすべてのファイルをまとめて選んでください。1つでも欠けると一部の写真が失われます。
  • 何度やっても安心：復元も読み込みも、新しいスマホにあるデータと統合されるので、既存の内容が消えることはありません。同じデータを何度復元・読み込みしても重複しません。移行が終わったら、新しいスマホで口座残高や最近の日記を確認してから古いスマホを整理しましょう。

家族の共有帳簿

  • 家族と同じ帳簿に記録：最大 3 人で 1 つの帳簿を使えます。各自のスマホで記録すると 1 分ほどで相手のスマホにも表示され、各記録の時刻の横に記録した人の名前が表示されます。
  • 共有されるのはこの帳簿だけ：同期されるのは共有帳簿の支出と収入だけです。日記・他の帳簿・口座・メモ・持ち物などの個人データは共有されず、家族のスマホにも表示されません。
  • 専用の Jianguoyun アカウントを用意：共有データは家族で使う WebDAV ドライブに保存されます。共有帳簿専用に新しい Jianguoyun アカウントを登録し、Web 版でアプリパスワードを発行してください（詳しい設定ガイドを見る👆）。WebDAV アドレスにはフォルダ名を含めてください（例：https://dav.jianguoyun.com/dav/jmsp/、フォルダ名は英数字がおすすめ）。iPhone や iPad で共有帳簿を作成する場合、フォルダがなければ自動で作成されます。Android で作成する場合は、先に Jianguoyun の Web 版でこのフォルダを作成してください。後から参加する家族はフォルダを気にする必要はありません。個人バックアップ用のアカウントは使わないでください（アプリでも拒否されます）。
  • 共有帳簿を作成：「マイページ」→「帳簿管理」→「👥 共有帳簿」で「新規作成」を選び、帳簿名・WebDAV アドレス・アカウント・アプリパスワードを入力します。作成後「招待コードをコピー」をタップして家族に送ってください。
  • 共有帳簿に参加：家族は同じページで「参加する」に切り替え、招待コードを貼り付けるだけで、Jianguoyun アカウントの入力は不要です。チャットアプリで転送されて前後に別の文字が付いていても認識できます。招待コードには共有ドライブのアカウントとパスワードが含まれるので、信頼できる人にだけ送ってください。
  • 編集・削除できるのは自分の記録だけ：他の人の記録は閲覧のみで、編集・削除・お気に入り・ピン留めはできません。自分の記録を削除すると、家族のスマホからも削除されます。
  • 口座はそれぞれ別：自分の記録はいつもどおり自分の口座残高に反映され、家族の記録は相手が使った口座名が表示されるだけで、あなたの口座には影響しません。
  • 共有帳簿で使えない機能：振替・貸し借り・積立・分割払い・返金・経費精算・予算・定期記録は共有帳簿では使えず、関連する項目は自動的に非表示になります。共有帳簿でショートカットや Siri から振替を記録すると、デフォルトの帳簿に記録されます。
  • メンバー別の統計：共有帳簿で統計ページを開くと、選択した期間のメンバーごとの支出・割合・収入が表示されます。
  • 同期のタイミング：アプリを開いている間は約 1 分ごとに同期し、10 分間変化がなければ 3 分ごとになります。アプリに戻ったときや共有帳簿ページで「今すぐ同期」をタップするとすぐに同期します。家族が記録すると「xx さんが n 件記録しました」と表示されます。バックグラウンドでは同期しません。
  • 同期状態：共有帳簿ページに最終同期時刻が表示されます。共有ドライブのアカウントやパスワードが使えなくなると、帳簿管理の「共有」バッジが赤い「同期失敗」に変わります。

🚪 共有をやめる・機種変更

  • 共有をやめる：共有帳簿ページで「共有をやめる」をタップすると枠が空き、この帳簿はあなたのスマホで通常の帳簿に戻り、既存の記録はそのまま残ります。あなたが記録した分は、他のメンバー（後から参加した人を含む）も引き続き見られます。やめるにはネット接続が必要です。
  • 機種変更：共有帳簿の記録は個人バックアップにも含まれるため、新しいスマホで復元すれば戻ります。ただし共有ドライブのアカウントは個人バックアップに含まれないので、招待コードでもう一度参加してください。再参加すると同じメンバーとして認識され、枠は増えません。
  • 人数の上限：共有帳簿は 1 つにつき最大 3 人で、1 人が参加できる共有帳簿は 1 つだけです。

データの安全とプライバシー

  • オフラインファースト：機内や電車などネットがない環境でもすばやく記帳や日記ができます。どの機能もネット接続を必要としません。
  • 端末優先、データはあなたのもの：記録や日記は初期状態では端末内にのみ暗号化して保存されます。あなたのデータを読み取る中央サーバーは一切運営していません。クラウドバックアップはあなた自身のアカウントを使うので、データは常にあなたの手元にあります。
  • 認証と通信の安全性：iCloud、WebDAV、Baidu Netdisk、Google Drive、OneDrive への接続は、各社公式の暗号化方式であなたのアカウントに直接つながります。ログイン情報はこの端末にのみ保存され、第三者のサーバーを経由することはありません。
  • アプリロック：4桁のパスコード、Face ID、指紋認証に対応。「離れて数分後にロック」も設定でき、他人に勝手に見られるのを防ぎます。
  • 必要なときだけ権限を使用：位置情報・写真・通知などの権限は、関連する機能（日記の周囲情報やリマインダーなど）を使うときだけ利用し、許可なくバックグラウンドで収集することはありません。

便利な使い方

  • ダブルタップで拡大：ホーム画面で文章の吹き出しをダブルタップすると全画面で拡大表示され、長い日記も読みやすくなります。

  • 複数選択でまとめて操作：長押しメニューで「選択」をタップすると複数選択モードになり、まとめて削除したり、複数日の日記をまとめてコピー。

  • いつでも感想を追記：日記の吹き出しの下にある「📝 感想を追記」をタップすると、本文はそのままで感想や後日談を書き足せます。
  • クレジットカードの支払いリマインダー：「資産口座」でクレジット口座を作成するときは、支払日も設定しておきましょう！期日前にお知らせするので、支払い忘れを防げます。
  • 📱 iPhone のホーム画面ウィジェット：ホーム画面の何もない所を長押し → 左上の「編集」→「ウィジェットを追加」（iOS 17 以前は左上の「+」）→「Daily Trifles」を検索すると、次のウィジェットを追加できます：収支サマリー、クイック記録（記帳／日記）、あの日の今日、ランダムに振り返る、リマインダー。
    🔒 ロック画面ウィジェット：ロック画面を長押し →「カスタマイズ」→「ロック画面」→ 時刻の下の領域をタップして「Daily Trifles」を検索します。
    🤖 Android のホーム画面ウィジェット：ホーム画面の何もない所を長押し →「ウィジェット」→「Daily Trifles」を探すと、収支サマリー、クイック記録、あの日の今日、ランダムに振り返る、リマインダーを追加できます。「マイページ → ホーム画面ウィジェット」からワンタップで追加することもできます。

よくある質問とコツ (FAQ)

1. 過去の日記や記録を後から追加するには？

シーンに合わせて2つの方法があります：

方法1：1件ずつすばやく追加（ちょっとした修正に）
画面下の 日記、または 手入力パネルを開き、いちばん上または左にある「日時」をタップして過去の日付に変更するだけ。保存すると、その日付の記録として自動で整理されます。

方法2：タイムマシンモード（1日分をまとめて追加）
ホーム画面左上のカレンダーアイコンをタップし、追加したい日を選んで右上の「後から記録」をタップします。ホーム画面上部に「⏳ 後から記録中」のバナーが表示され、ひと言の送信、手入力、日記など、すべての記録がその日に「タイムトラベル」します！終わったらバナーの「終了」をタップすれば現在に戻ります。

また、ホームの入力欄に「2025年8月1日 タクシー 50」のように入力すれば、8月1日の記録を追加できます。

2. 投稿済みの日記や記録を修正するには？

記録全体を修正：ホーム画面の吹き出しを長押しし、表示されたメニューで「編集」を選びます。

記録内の1項目を修正：1つの記録に複数のカテゴリ（食材とタクシーなど）が含まれていても、入力し直す必要はありません！吹き出しの中で該当するカテゴリのラベルをタップすると編集画面が開き、その項目の金額やカテゴリを修正できます。

3. 記録内の1項目だけを削除するには？

吹き出しのカテゴリのラベルをタップして編集画面を開き、右上の 🗑️ ゴミ箱アイコンから「項目を削除」を選びます。吹き出し内の項目がすべて削除され、写真もない場合は、吹き出しごとタイムラインから消えます。

4. 過去の記録が多すぎて探せないときは？

ホーム画面右上の 🔍 虫眼鏡アイコンをタップすると、キーワードで何でも検索できます。下のよく使う「#タグ」をタップして絞り込むこともできます。「日記」タグは日記のみ、「帳簿」タグは記録のみを表示します。

5. AI の API キーを取得・設定するには？

API キーをワンタップで取得できる機能を現在開発中です。今後のアップデートをお楽しみに！
現在は、 SiliconFlow、Zhipu、DeepSeek や Groq の公式サイトで登録し、無料の API キーを取得してください。
取得したら、アプリの「マイページ → AI エンジン」で入力して保存すれば、AI によるクイック記帳が使えるようになります。

6. 記録や日記のデータはどこに保存される？消えることはある？

Daily Trifles はオフラインファーストの設計で、すべてのデータは初期状態で端末内に暗号化して保存され、あなたのプライバシーを取得する中央サーバーはありません。スマホを紛失してもデータを失わないよう、設定で iCloud、WebDAV、Baidu Netdisk、OneDrive、Google Drive のいずれか（複数も可）の自動バックアップを必ずオンにしてください。

7. 写真のアップロードに失敗することがあるのはなぜ？

アプリを快適に動かし、端末の容量を使いすぎないよう、写真のアップロードは1日20枚までに制限し、バックグラウンドで圧縮しています。上限に達したら翌日にお試しください。

8. お気に入りやピン留めした記録をすばやく探すには？

ピン留め：ホーム画面右上の 🔍 をタップし、何も入力しなければ、検索画面が「専用ボード」になり、ピン留めした内容がすべて表示されます。

お気に入り：同じ検索画面の下にあるタグ欄に「#お気に入り」が固定されていて、タップするとお気に入りの思い出や記録がすぐに表示されます。

9. 「時の記録」の累計記録日数はどう数える？

その日にアプリで何か1つでも記録すれば、少額の記録でも一行だけの日記でも、その日は記録達成としてカウントされます。毎日少しずつ記録して、どこまで続くか試してみましょう！

10. 吹き出しの文字が小さくて見づらいときは？

「マイページ → テーマ」で「システムの文字サイズに合わせる」をオンにすると、端末で設定した大きな文字サイズ（シニアモードなど）に合わせて表示されます。細かく調整したい場合はオフにして、下のスライダーで吹き出しの文字サイズを調整できます。

公式サイトにログインし、「アカウント情報」->「セキュリティ設定」を開きます。

「サードパーティアプリ管理」で「アプリを追加」をタップし、アプリ名に「Daily Trifles」と入力してパスワードを生成します。
